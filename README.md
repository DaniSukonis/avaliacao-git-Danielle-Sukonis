Este projeto foi realizado no âmbito da avaliação de Git e GitHub do curso Técnico/a de Desenvolvimento de Software.

Durante a atividade foram praticados comandos básicos do Git e a utilização do GitHub.

## Instalação

1. Instalar o Git.
2. Criar ou abrir a pasta do projeto.
3. Inicializar o repositório Git.
4. Adicionar os ficheiros ao repositório.
5. Fazer o commit das alterações.
6. Enviar o projeto para o GitHub.

```bash
git init
git add .
git commit -m "Adicionar README"
git push
```

## Ficheiros

O projeto contém o ficheiro `README.md`, que apresenta as informações e a documentação da atividade.

O ficheiro `config.txt` contém as informações de configuração utilizadas como exemplo nesta atividade.

**Nota importante:** O ficheiro README.md deve estar guardado na pasta do projeto para aparecer na página principal do repositório no GitHub.
